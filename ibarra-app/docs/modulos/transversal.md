# Servicios transversales

## Resumen

Incluye dashboard, login, guards, PWA, componentes shared y servicios comunes.

## Código y relaciones

Las piezas principales están en `src/app/components/dashboard`, `login`, `access-denied`, `pwa-install-popup`, `shared`, `src/app/guards` y `src/app/services`. Todos los módulos dependen de esta capa para navegación, sesión y permisos.
